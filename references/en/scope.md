SCOPE-1

Read when creating or improving a skill. Inputs: goal, representative input, expected artifact and recipient environment. Select create, capture, improve or onboard. Record only requirements relevant to this task. Define observable completion, required inputs and author resources unavailable to recipients.

Instruction-only work needs no runtime. Improve a copy in an isolated directory. Baseline: Windows 11 x64; Codex is tested first, WorkBuddy awaits recipient validation. Installation does not prove task success. Without execution evidence use declared or unknown. Continue to capture or dependencies.
