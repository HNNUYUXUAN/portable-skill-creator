# Codex

HOST-1

浏览器首次配置：在桌面应用 Settings → Computer Use 安装或管理官方扩展，在实际使用的 Chrome 配置中启用；回到当前聊天选择对应浏览器，按站点要求完成授权，再用工具列出/读取目标标签页。扩展存在但无标签页时，先核对浏览器配置和共享状态，不反复重装。登录过期由接收者登录，权限失败保留具体阻塞。[官方浏览器配置](https://learn.chatgpt.com/docs/chrome-extension)。

使用宿主实际提供的文件与终端工具，读取工具文档后调用；不猜测工具名称。浏览器任务优先使用已配置的浏览器连接器，先做只读页面探测，核对目标标签页。工具可见不等于浏览器已连接。剪映等原生应用另需桌面工具。独立创建器安装至用户技能目录，保留系统 skill-creator。
