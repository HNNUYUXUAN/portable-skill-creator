# onboard

SETUP-1

首次在接收端使用时读取。先用宿主文件工具确定技能根，再用系统 PowerShell 执行 bootstrap.ps1。可用 -Python 显式指定真实 3.12；没有运行时时 -Prepare 在用户目录下载已锁定的 uv 并创建环境。不要把作者解释器路径写进技能。受限网络或执行策略需输出具体恢复指引，不能绕过组织策略。

bootstrap ready 仅表示创建器解释器可用。对目标技能再运行 doctor：它只检查已声明的环境变量存在性和命令位置，不验证浏览器或云账号。依赖的真实调用和产物需独立验证。

配置模板不含真实 Key；明确 .env/环境变量/其他配置的真实优先级。缺 Key 时已有音频可本地处理；新音频缺 ASR 就报告需配置，不能编造字幕。账号地域、模型、端点和音色由接收者确认。云端样例仅在已有授权下调用，区分 key_present/account_verified/sample_completed。结果未知先查请求状态。完成标准：必需条件已验证或逐项列出阻塞。
